Away from the desk

Things I've built

  • Digital ammeter

    A small current meter built as a course electronics project. A sensor sits in series with the load, a microcontroller reads its voltage and turns it into milliamps, and the reading is shown live. It was checked against a multimeter until the two agreed.

    Arduino, Current sensor, Electronics

  • Clap-controlled light

    Clap once and the light turns on, clap again and it turns off. A microphone module feeds the Arduino, which looks for a sharp spike in sound and switches the light through a relay. Most of the work was tuning it so talking does not trigger it.

    Arduino, Sound sensor, Relay

  • Student result calculator

    A C program that takes the marks for each subject and prints the grade, grade point, total and GPA, using the grading scale from school.

    C
