# Your personal folder

Everything that makes this site yours is in this folder.

| File | What |
|---|---|
| `profile.yaml` | all text: name, about, education, projects, links |
| `photos/profile.jpg` | your portrait (4:5, at least 800 px wide). Now a placeholder |
| `photos/avatar.jpg` | small square version of your photo. Now a placeholder |
| `photos/project-1.jpg` … | picture for the 1st, 2nd … project in `profile.yaml` |
| `photos/hobby-1.jpg` … | photo for the 1st, 2nd … hobby |
| `photos/edu-1.jpg` … | optional photo for the 1st, 2nd … education entry (newest first) |
| `photos/award-1.jpg` … | optional certificate for the 1st, 2nd … achievement |
| `photos/hl-*.jpg`, `about-marigold.jpg`, `contact-flowers.jpg` | the garden photos on Home, About and Contact |
| `blog/<post-name>.jpg` | cover image for a blog post |
| `cv.pdf` | your CV (download button) |

Rules:
- Keep the exact file names. `.jpg`, `.png` and `.webp` all work.
- To replace a photo, upload your own file with the same name.
- A missing optional file simply hides that picture. An empty line in `profile.yaml` hides that part.
